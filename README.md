# Rust Crypto

Curso de Jeresoft Academy sobre criptografía en Rust: hashes, cifrado
simétrico, criptografía de clave pública, integridad y protocolos. El curso
implementa modelos para comprender y siempre diferencia aprendizaje de uso en
producción, donde se requieren bibliotecas auditadas.

La fuente de verdad es el [plan versionado](docs/superpowers/plans/2026-07-30-rust-crypto-course.md).
La ejecución vive en el [GitHub Project #23](https://github.com/users/jeresoftx/projects/23).

## Estado editorial

El curso está completo como borrador técnico. No está revisado ni publicado:
requiere revisión humana conforme a RFC-0001 §20.
